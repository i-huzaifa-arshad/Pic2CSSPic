# Pic2CSSPic Desktop

Pic2CSSPic is a standalone desktop app (Electron) that converts uploaded images into blocky CSS pixel art using `box-shadow`.

## Run locally

```bash
npm install
npm start
```

## Build a Windows `.exe`

```bash
npm install
npm run build:win
```

Build output will be placed in `dist/`:
- `Pic2CSSPic Setup *.exe` (installer)
- `Pic2CSSPic *.exe` (portable executable)

After installing, it opens like a normal Windows desktop application.
